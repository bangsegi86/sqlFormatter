# Oracle SQL 포매터 (포터블 데스크톱 앱)

한 줄로 붙여넣은 Oracle 쿼리를 읽기 좋게 정리해 주는 도구예요.
왼쪽은 원본, 오른쪽은 정리된 결과이고, 오른쪽 옵션 패널을 바꾸면 결과가 바로 바뀝니다.
설치도 라이선스 키도 없고, 쿼리는 PC 밖으로 나가지 않아요 (네트워크 사용 없음).

## exe 만들기 (내 PC에서)

필요한 것은 **Windows + Node.js 18 이상**뿐이에요.

1. 이 폴더를 통째로 PC에 풀어요.
2. `build-win.bat` 을 더블클릭해요. (패키지 설치 → 테스트 → exe 생성을 차례로 해요)
3. `dist\OracleSqlFormatter-1.0.0-portable.exe` 가 만들어져요. 이 파일 하나만 복사해서 쓰면 돼요.

직접 명령어로 하려면:

```
npm install
npm test          # 엔진 테스트 49개
npm run build:editor  # 편집기(CodeMirror) 묶음 다시 만들기 — tools/editor-entry.js → src/vendor/codemirror.js (평소엔 필요 없어요)
npm start         # 개발 모드로 바로 실행해 보기
npm run dist      # 포터블 exe 만들기
npm run icon      # 아이콘 다시 만들기 (tools/make-icon.js → src/assets/icon.ico · icon.png)
```

처음 빌드할 때는 Electron(약 100MB)을 내려받아요. 만들어지는 exe는 약 70~90MB예요.
포터블 exe는 프리셋·설정을 **exe 옆의 `OracleSqlFormatter-data` 폴더**에 저장해요. exe와 같이 옮기면 설정도 따라와요.

## 쓰는 법

| 하고 싶은 일 | 방법 |
| --- | --- |
| 정리하기 | 왼쪽에 붙여넣거나 입력 (자동 포맷이 켜져 있으면 바로 정리돼요) / `포맷 실행` / `Ctrl+Enter` |
| 결과 가져가기 | `복사` (`Ctrl+Shift+C`) 또는 `.sql 저장` (`Ctrl+S`) |
| 파일로 열기 | `파일 열기` (`Ctrl+O`) 또는 .sql 파일을 왼쪽에 끌어다 놓기 (UTF-8, EUC-KR 자동 인식) |
| 결과를 바로 고치기 | 결과 칸을 눌러 그대로 고쳐요 (구문 강조 유지 · 커서가 있는 줄은 연하게 음영). `Tab`/`Shift+Tab` 은 공백으로 들여쓰기/내어쓰기, `Ctrl+Z` 되돌리기. 고치면 `직접 수정함` 표시가 붙고 복사 · 저장은 고친 내용으로 해요. 옵션을 바꾸거나 다시 포맷하면 새 결과로 바뀌는데, 알림의 `되돌리기` 로 고친 내용을 되살릴 수 있어요 |
| 찾기 · 바꾸기 | `Ctrl+F` 찾기, `Ctrl+H` 바꾸기 (누른 칸 — 원본 또는 결과 — 에서 찾아요). `Enter`/`Shift+Enter` · `F3` 다음/이전, `Aa` 대소문자 구분, `단어` 단어 단위. `모두 바꾸기` 는 `Ctrl+Z` 한 번으로 되돌려요. 접힌 곳 안에서 찾으면 자동으로 펼쳐요 |
| IF 접기 (결과 칸) | 엑셀 그룹처럼 왼쪽 막대의 `[−]`/`[+]` 상자로 IF ~ END IF 를 접어요. ELSIF · ELSE 가 있으면 누를 때마다 조건 줄만 보기 → 통째로 접기 → 펼치기. ELSIF · ELSE 줄의 점선 상자는 그 가지만 접어요. 위쪽 `IF 단계 1 2 3 …` 은 한 번에 접기 (1 = 전체 접기, 마지막 = 전체 펼치기). `Ctrl+Shift+[` / `]` 커서 위치 접기/펼치기, `Ctrl+K` 뒤 `Ctrl+0` / `Ctrl+J` 전체 접기/펼치기. 접어도 복사 · 저장은 전체 내용이에요 |
| 지금 위치 확인 | 결과 칸 위쪽 `현재 위치` 에 커서가 있는 IF · ELSIF 경로가 나와요. 누르면 그 줄로 가요 |
| 결과를 다시 손보기 | `원본으로` 로 결과를 왼쪽으로 옮겨요 |
| 덩어리마다 설명 달기 | 결과 칸 위 `구조 · 설명` 을 눌러요. 덩어리(SQL 문장 · IF · 반복문 …) 첫 줄 옆에 설명 칸이 붙어요. 아래 [구조 · 설명 화면](#구조--설명-화면) 참고 |
| 옵션 이해하기 | 옵션 이름 옆 `?` 에 마우스를 올리면 예시가 나와요. 기본값과 다른 옵션 · 탭에는 파란 점이 붙어요 |
| 실수 되돌리기 | 지우기 · 붙여넣기 · 예제 · 원본으로 · 옵션 초기화 · 프리셋 적용 뒤 나오는 알림의 `되돌리기` |
| 프리셋 고쳐서 덮어쓰기 | 프리셋을 고른 뒤 옵션을 바꾸고 `프리셋 저장` → 이름이 미리 채워져 있으니 `Enter` |
| 팀 표준 공유 | `프리셋 저장` 후 `⋯ → 프리셋 내보내기` 로 .json 을 나눠 줘요 |

자동 포맷을 끄면 `포맷 실행` 버튼이 강조되고, 원본을 고친 뒤 아직 정리하지 않았으면 결과 위에 `이전 결과` 표시가 붙어요.

## 구조 · 설명 화면

몇천 줄짜리 프로시저를 분석할 때, 덩어리마다 설명을 달고 그 설명을 덩어리 위에 주석으로 넣는 화면이에요. 인터넷 없이 PC 안에서만 동작해요.

- **설명 칸이 덩어리 옆에 붙어요.** 결과 칸 왼쪽에 덩어리마다 한 줄짜리 설명 칸이 그 덩어리 첫 줄과 같은 높이에 있어요. 긴 쿼리를 지나는 동안엔 위에 고정돼요. 안쪽 덩어리는 `4.1` 처럼 번호가 붙고 한 칸씩 들여 보여요.
- **덩어리**: SQL 문장, IF, CASE, 반복문, 안쪽 BEGIN~END, 커서 명령, COMMIT, 이어진 `:=` 대입문, 프로시저 호출, 선언부, EXCEPTION. 패키지 본문의 프로시저 · 함수도 각각 덩어리예요.
- **설명 넣기**: 입력한 설명은 코드에 흐린 미리보기 줄로 보이고, `주석으로 넣기` 를 누르면 덩어리 바로 위에 주석이 들어가요 (`-- [3] 설명` / `/* [3] 설명 */` / `-- 설명`). 알림의 `되돌리기` 나 `Ctrl+Z` 로 취소해요.
- **다시 읽기**: 덩어리 바로 위 주석 한 줄은 그 덩어리의 설명으로 읽어요. 고치고 다시 넣으면 새로 추가하지 않고 그 줄을 바꾸고, 비우고 넣으면 지워요. 순서가 바뀌어 `[번호]` 가 안 맞으면 `번호 다시 매기기` 가 나와요.
- **옮기기**: 카드의 `⠿` 를 끌거나 `↑` `↓` / `Alt+↑` `Alt+↓` 로 같은 단계 안에서 옮겨요. 덩어리 위 주석도 같이 움직여요. 다른 블록 안(다른 IF 가지 등)으로는 옮기지 않고, 선언부 · EXCEPTION 은 고정이에요. 값을 넣는 덩어리와 그 값을 쓰는 덩어리의 순서가 바뀌면 알림으로 알려줘요 (변수 이름으로만 판단해요).
- **길 찾기**: 오른쪽 지도(초록 = 설명 넣음 · 파랑 = 입력함 · 회색 = 없음)를 누르면 그 위치로 가요. `F8` 또는 설명 칸에서 `Enter` = 설명 없는 다음 덩어리. `덩어리 찾기` 는 설명이나 쿼리 글자로 찾아요. 위쪽 `현재 위치` 는 화면 맨 위 덩어리와 그 바깥 덩어리를 보여줘요.
- **덩어리만 보기**: 쿼리 본문을 접고 덩어리 첫 줄만 보여줘요. 멀리 옮길 때 편해요.
- 설명을 넣거나 옮기면 결과를 직접 고친 것이라 `직접 수정함` 이 붙어요. 이 상태에서 옵션을 바꿔 다시 정리하면, 넣어 둔 설명은 새 결과에 미리보기로 다시 나와요 (`주석으로 넣기` 로 다시 넣어요).
- 결과 칸이 좁으면 설명 칸 자리를 만들려고 옵션 패널을 접어요 (`Ctrl+B` 로 다시 열어요).

## 옵션 (7개 탭, 63개)

옵션 이름 옆 `?` 에 마우스를 올리면 자세한 설명과 예시가 나와요. 선택 버튼에 올리면 그 선택의 설명이 나와요.
다른 옵션 때문에 지금은 효과가 없는 옵션은 흐리게 보이고, 그 이유가 노란 글씨로 나와요.

줄 길이 제한은 없어요. 글자 수 때문에 줄을 바꾸지 않고, 아래 옵션에서 정한 위치에서만 줄을 바꿔요.
대신 "복잡한 식"인지를 구조로 판단해요. CASE · 서브쿼리가 있거나 함수 안에 함수가 있는 항목은 다른 항목과 한 줄로 묶지 않아요.

- **기본**: 키워드 대소문자, 절 정렬(오른쪽 River/왼쪽), 탭 → 공백 칸 수, 비교·연결 연산자 공백, 비교 연산자 세로 정렬, 문장 끝 문자(; / 없음)
- **컬럼**: 콤마 위치(뒤/앞), 한 줄당 컬럼 수(1·2·3·전부), 항목이 N개 이하면 한 줄로, INSERT 목록이 N개 이하면 한 줄로, FROM 별칭 세로 정렬, 줄 끝 주석 위치
- **표현식**: CASE 줄바꿈(WHEN마다/복잡하면/한 줄) · THEN 위치 · END 위치, 긴 연산식 줄바꿈(덧셈·뺄셈 `+ -` · 문자 연결 `||`, 항이 N개 이상일 때, 함수 안의 식에도 적용), DECODE 줄바꿈, DECODE→CASE, NVL→COALESCE
- **서브쿼리**: 서브쿼리 괄호(붙여서/따로 줄에), 인라인 뷰 괄호, 스칼라 서브쿼리(항상 여러 줄/단순하면 한 줄), 조인 표기(콤마 조인→ANSI JOIN), IN 목록 한 줄 최대
- **PL/SQL**: 정리/원문 유지, 들여쓰기 칸 수, IF 조건 줄바꿈(N개 이상), THEN · LOOP 위치, 파라미터 배치, 세로 정렬
- **빈 줄**: 원본 빈 줄 유지 · 연속 빈 줄 최대 · 문장 사이 빈 줄 /
  덩어리 앞뒤(안 넣음 · 앞 · 뒤 · 앞뒤): SQL 문장, IF, CASE, 반복문, 안쪽 BEGIN~END, 커서 명령, 여러 줄 프로시저 호출, COMMIT · ROLLBACK, 주석 줄 앞, 선언 종류가 바뀔 때 /
  블록 안쪽 경계(원본대로 · 넣기 · 빼기): IS 다음, 선언부와 BEGIN 사이, BEGIN 다음, THEN · ELSE 다음, ELSIF · ELSE 앞, END IF 앞, LOOP 다음, END LOOP 앞, EXCEPTION 앞, 예외 WHEN 사이, 블록 END 앞.
  기본값은 모두 "원본대로"라서 켜기 전에는 결과가 바뀌지 않아요. `IF SQL%ROWCOUNT` 도 IF 규칙을 따라요
- **별칭**: AS 키워드, 컬럼 별칭 자동 부여, 테이블 별칭 자동 부여, 자동 규칙(첫 글자/약어/순번), **별칭 일괄 변경**

별칭 일괄 변경은 문자열 치환이 아니라 쿼리 구조를 분석해서 같은 범위(메인 쿼리·서브쿼리)의 별칭과 참조만 바꿔요.
이미 쓰는 이름이거나 예약어면 바꾸지 않고 이유를 알려줘요.

## 지원 범위

- 지원: `SELECT`(WITH, UNION/MINUS/INTERSECT, 서브쿼리, 인라인 뷰, 분석함수, CONNECT BY, FOR UPDATE, FETCH), `INSERT`(VALUES / SELECT), `UPDATE`, `DELETE`, `MERGE`
- PL/SQL: `CREATE PROCEDURE · FUNCTION · PACKAGE [BODY] · TRIGGER`, `DECLARE` / `BEGIN` 블록
  - 블록(`IS` · `BEGIN` · `IF/ELSIF/ELSE` · `LOOP/WHILE/FOR` · `CASE` · `EXCEPTION`) 안을 한 단계씩 들여써요.
  - 블록 안 SQL(SELECT INTO · INSERT · UPDATE · DELETE · MERGE · 커서 쿼리 · `FOR r IN (SELECT ...)` · `OPEN c FOR`)은 다른 탭의 쿼리 옵션대로 정리해요.
  - 파라미터 · 변수 선언 · RECORD 필드 · 연속된 `:=` 대입문을 세로로 맞추고, 주석이 달린 프로시저 호출 인자는 한 줄에 하나씩 써요.
  - 해석하지 못한 문장은 그 문장만 원문 그대로 두고, 블록 짝(IF ~ END IF 등)이 맞지 않으면 블록 전체를 원문 그대로 두고 알려줘요.
- 주석(`--`, `/* */`)과 힌트(`/*+ */`), 바인드 변수(`:name`), `q'[...]'` 문자열, 한글·따옴표 식별자를 보존해요.
- 지원하지 않는 구문(CREATE TABLE 등 DDL, CREATE TYPE, COMPOUND TRIGGER, MODEL 절, 다중 테이블 INSERT)은 **원문 그대로 두고** 오류 위치를 알려줘요. 쿼리를 망가뜨리지 않는 것이 원칙이에요.
- 한 문장이 해석 실패해도 같은 입력의 다른 문장은 정상적으로 정리해요.

## 알아둘 점

- ANSI JOIN 변환은 콤마 조인을 모두 바꿔요 ((+) 없음 → INNER JOIN, (+) → LEFT/RIGHT OUTER JOIN). 안전하게 바꿀 수 있는 경우(OR 없음, 테이블이 조인 조건으로 서로 연결됨)에만 바꾸고, 아니면 원문을 두고 이유를 알려줘요. 결과는 꼭 한 번 확인하세요.
- DECODE→CASE 변환은 NULL 비교 규칙(DECODE는 NULL=NULL을 같다고 봄)을 맞춰서 `IS NULL` 조건으로 만들어요.
- 줄 끝 주석은 항목 끝에 그대로 두고, 위치를 알 수 없는 주석은 결과 맨 아래로 옮기고 알려줘요.
- 결과에는 탭을 쓰지 않고 공백만 써요. 원본의 탭(주석 · 원문 그대로 둔 부분)도 탭 간격(기본 4칸, 한글은 2칸으로 계산)에 맞춰 공백으로 바꿔요. 문자열 값 안의 탭만 데이터라서 그대로 둬요.
- 한글 폭 때문에 글꼴이 등폭이 아니면 정렬이 어긋나 보일 수 있어요. 화면은 D2Coding → Consolas → Noto Sans Mono CJK 순으로 써요.

## 구조 (고치고 싶을 때)

```
main.js                  Electron 진입점
src/engine/              포맷 엔진 (화면과 분리, Node 에서도 동작)
  tokenizer.js           주석·힌트·q'[]'·바인드·(+) 구분
  parser.js              SELECT/WITH/DML → 구조 트리
  render.js              옵션별 배치 (River 정렬, 콤마, CASE, DECODE, 서브쿼리)
  transform.js           DECODE→CASE, NVL→COALESCE, 콤마 조인→ANSI JOIN
  alias.js               별칭 분석·일괄 변경·자동 생성
  plsql.js               PL/SQL 블록 구조 들여쓰기 (안쪽 SQL 은 render.js 로)
  ifblocks.js            IF ~ ELSIF ~ ELSE ~ END IF 짝 찾기 (결과 칸 접기용)
  options.js             옵션 정의 (화면과 엔진이 공유)
src/renderer/            화면 (editor.js: 원본 · 결과 편집기, IF 접기 막대, 찾기 · 바꾸기)
src/vendor/codemirror.js 편집기 라이브러리 묶음 (CodeMirror 6, MIT) — 앱 안에 들어 있어 인터넷 없이 동작
src/assets/              앱 아이콘 (icon.ico: exe·작업표시줄, icon.png: 창)
tools/make-icon.js       아이콘 생성 스크립트 (외부 패키지 없이 동작)
```
